# Enterprise Engineering Framework (EEF) - ASBP

## Principios

- Generación basada en DSL
- Separación IA/lógica/ejecución
- Arquitectura modular
- Iteración continua

## Capas

1. Experience Layer
2. API Layer
3. Orchestration Layer
4. AI Agent Layer
5. DSL Layer
6. Code Generation Layer
7. Execution Layer
8. Infrastructure

## Flujo

User Input → AI Interpretation → DSL Generation → Code Generation → Validation → Execution

## Estándares

- Backend: Node.js / NestJS
- Frontend: React / Next.js
- Infraestructura: Docker + Kubernetes
- CI/CD: Git + pipelines
